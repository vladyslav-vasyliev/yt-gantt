# YouTrack → Gantt

Диаграмма Ганта для задач YouTrack: строит дерево задач по типу связи, планирует
их по модели «родитель-обёртка» и показывает план и факт на одной временной оси.

Работает с любым инстансом YouTrack через REST API — нужен permanent token.

## Возможности

- **Дерево задач** — дочерние тикеты подтягиваются по выбранному типу связи
  (по умолчанию `parent for`), рекурсивно, всё поддерево до 500 задач.
- **План и факт** — верхний пунктирный бар: оценка (размер задачи в днях).
  Нижний сплошной бар: факт — от даты начала работ до Resolved; справа от него —
  реальная длительность в календарных и рабочих днях.
- **Настраиваемый расчёт (таб «Расчёт»)** — размер и дата начала работ
  вычисляются js-лямбдами `(issue, activities) => …`, которые можно
  редактировать прямо в приложении:
  - «Размер (дни)»: `(issue, activities) => number`; по умолчанию значение
    поля `Size` конвертируется по карте XS…XXL → 3/5/10/20/40/80 дней;
  - «Начало работ»: `(issue, activities) => Date | null`; по умолчанию — дата
    перехода в статус `Doing` по истории изменений;
  - `issue`: `{ id, summary, sizeRaw, resolved, resolvedAt, links, customFields }`
    (customFields — словарь «имя поля → значение»), `activities` — история
    `[{ ts, field, added[], removed[] }]`;
  - лямбды хранятся в localStorage, у каждой есть кнопка «сброс»; сломанная
    лямбда не роняет построение — используется дефолтная, ошибка попадает
    в предупреждения.
- **Расписание «родитель-обёртка»** — факты важнее плана: родитель отсчитывается
  от момента начала работ на дочерней, над которой раньше других начали работу,
  и закрывается по концу последнего ребёнка. Первый ребёнок стартует одновременно
  с родителем, каждый следующий sibling — после предыдущего. Корни без факта —
  от начала оси.
- **Масштабирование** — авто (8 недель на экран) или кнопками «−»/«+».
- **Сворачивание поддеревьев**, sticky-колонка задач, подсветка строк,
  тултипы с полными названиями, изменяемая ширина колонки задач
  (сохраняется в localStorage).
- **Тосты и предупреждения** — сетевые ошибки, недоступная история изменений,
  задачи без `Size` (берётся M с пометкой) и лимиты дерева не проходят молча.

## Быстрый старт

```bash
npm ci
npm run build
node server.cjs
# → http://localhost:8414
```

`server.cjs` раздаёт собранную статику из `dist/` и проксирует `/yt/*` на
YouTrack — так браузер не упирается в CORS. Без прокси (просто открыть
`dist/index.html`) запросы к YouTrack, скорее всего, будут заблокированы.

Адрес YouTrack и token задаются на табе «Подключение» и хранятся только
в localStorage браузера.

## Режим разработки

```bash
node server.cjs   # прокси /yt → YouTrack на :8414
npm run dev       # Vite dev-сервер на :5173, /yt проксируется в server.cjs
```

## Тесты

```bash
npm test              # unit-тесты (Vitest): дерево, расписание, YouTrack API
npm run typecheck     # tsc --noEmit
npm run check         # typecheck + unit
npm run test:screenshot   # скриншотные e2e-тесты (Playwright, мок YouTrack API)
```

Скриншотные тесты поднимают `server.cjs` автоматически и мокают YouTrack через
`page.route` — реальный бэкенд не нужен.

## Структура

```
src/
  App.tsx                # состояние, загрузка/построение, тосты
  components/
    SettingsForm.tsx     # настройки: табы «Задачи», «Расчёт», «Подключение»
    GanttChart.tsx       # диаграмма: MUI Table + SVG-бары
  lib/
    constants.ts         # константы, чистые помощники, localStorage
    lambda.ts            # пользовательские лямбды расчёта (компиляция, дефолты)
    youtrack.ts          # REST API: issues + activities (история полей)
    tree.ts              # дерево связей + модель расписания
server.cjs               # статика dist/ + прокси /yt (без зависимостей)
tests/                   # Vitest-тесты и Playwright-скриншоты
```

## API YouTrack

Используются два запроса на задачу:

- `GET /api/issues/{id}` — поля, `customFields` (Size, State), `links`;
- `GET /api/issues/{id}/activities?categories=CustomFieldCategory` — история
  изменений полей, из неё берётся дата перехода в «Статус начала работы».

Token создаётся в YouTrack: *Profile → Account Security → Permanent Tokens*.
Права: чтение issues и истории (`activities`).

## Ограничения

- Максимум 500 задач в дереве (предохранитель, дальше поддерево обрезается).
- Дефолтные лямбды рассчитывают на поля `Size` и статус `Doing` — если в вашем
  проекте они называются иначе, поправьте лямбды на табе «Расчёт».
- История `activities` требует прав на неё: если токен их не имеет, даты факта
  не определятся (приложение предупредит тостом и в списке предупреждений).
